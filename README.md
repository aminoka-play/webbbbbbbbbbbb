## Как запустить

1. Распакуйте ZIP-архив в любую папку.
2. Откройте файл `index.html` двойным кликом (или правой кнопкой → «Открыть с помощью» → браузер).
3. Интернет нужен только для загрузки шрифтов Google Fonts. Без него сайт тоже работает, но шрифты заменятся на Arial.

Чтобы проверить мобильную версию: откройте сайт в Chrome, нажмите **F12**, затем значок телефона (Toggle device toolbar) и выберите ширину 320–768 px.

## Реализованные JavaScript-функции

1. **Переключение светлой и тёмной темы.**
   Кнопка 🌙 в шапке добавляет или убирает класс `dark` у `body`, и CSS меняет цвета всей страницы. Выбранная тема сохраняется в `localStorage`, поэтому при переходе на другую страницу и при перезагрузке она не сбрасывается.

2. **Мобильное меню.**
   На экранах до 768 px меню скрывается, а кнопка ☰ открывает и закрывает его (класс `show`). После нажатия на пункт меню оно закрывается само.

3. **Кнопка «Наверх».**
   Круглая кнопка ↑ в правом нижнем углу плавно прокручивает страницу к началу.

## HTML и CSS

- Используются смысловые теги: `header`, `nav`, `main`, `section`, `footer`.
- CSS и JavaScript подключены отдельными файлами (`style.css`, `script.js`).
- Адаптивность сделана через `@media` для ширины 992 px, 768 px и 480 px. На телефоне блоки становятся в колонку, а карточки проектов листаются по горизонтали.
- Шрифты: Inter и Plus Jakarta Sans (Google Fonts), запасной шрифт Arial.
- Все ссылки меню, кнопок и резюме работают.
